# Advent of Code

My solutions to [Advent of Code](https://adventofcode.com), one folder per day: `YYYY/DD/`.

Run a day with `./aoc run 2024 1`, start one with `./aoc new 2025 3 rust`. Inputs are not committed; get yours with `./aoc fetch 2024 1`.
